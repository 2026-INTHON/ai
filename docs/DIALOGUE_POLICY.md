# 실시간 대화 지침 · 맥락 전달

`evaluation_prompt.py`는 실시간 입력, `learning_policy.py`는 공통 규칙, `learning_examples.py`는 판정 사례를 관리한다. 모델·성우 설정은 변경하지 않는다.

## 판정 경계

- O: 적절한 응답. 정중한 거절·개인 경계·다른 취향·관련 질문·자연스러운 장소 변경도 가능하다.
- △: 맥락에 맞고 협조적이지만 표현·격식·뉘앙스가 아쉽다. 사소한 문법·높임말 실수만으로 X를 주지 않는다.
- X: 명확한 무시·비하·빈정거림·부적절한 요구, 핵심 의도 오해, 연결 설명 없이 완전히 다른 화제로 답하기. 욕설이나 반복 공격까지 기다리지 않는다.
- ?: 의미 자체를 판단하기 어려운 단편·모호한 말·음성 인식 오류 의심.

무례하지 않은 화제 이탈 X에는 설명(`request_clarification`), 무례한 발언에는 사과/소명(`request_apology`)을 요청한다. 해소 전에 원래 질문으로 강제 복귀하지 않는다. 사과 수용과 감정 회복은 별개이며 성격·누적 감정에 따른 회복을 유지한다.

BE가 체력을 결정한다. 신뢰도 0.75 미만 X는 ?로 보류한다. 모국어라는 이유만으로 차감하지 않지만, 모국어로 한 명백한 모욕을 △로 바꾸지도 않는다. 기존 기록은 재채점하지 않는다.

## 맥락과 분량

- 내부 `history`는 `{prompt?, user, npc}` 최대 100턴. BE의 기존 세션 상한에 맞춘다. 질문이 없는 과거 기록도 읽는다.
- 최근 12턴 자르기를 제거했다. 실제 질문·답·캐릭터 반응을 순서대로 전달한다. 연속된 NPC 반응과 다음 질문이 같으면 한 번만 넣으며, 마지막 반응은 현재 `npcText`와 중복될 때만 생략한다. 임의 요약/삭제를 하지 않는다.
- 상황은 시작 배경이다. 대화 중 변경한 장소·약속이 우선한다. 현재 갈등·감정·말투 상태도 매 요청에 보낸다.
- 선택한 성격의 전기·직업·관심사·취향·말투·규칙은 보존한다. 카드와 상세 프로필의 같은 사실은 합치고 UI 홍보 문구와 내부 버전 정보는 제외한다.
- 미래 체크포인트는 목표만 보낸다. 아직 말하지 않은 대사·모범 답안을 실제 사건처럼 취급하지 않는다.
- 기존 사용자 판정 사례를 모두 보존하고 경계 사례를 추가했다. 반복 규칙을 합쳐 공통 지침은 약 40% 감소했다(문자 수, 출력 스키마·실제 대화 제외).

자동 테스트는 100턴의 초기 사실 보존, 질문 재시도, 프로필 정보 보존, 모국어와 X의 구분, 갈등·말투·종료 조건을 확인한다. 실제 모델도 대표 사례로 검증하며 확률적 출력의 완전한 일관성을 보장하지는 않는다.
