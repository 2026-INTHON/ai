# 임시 대화 반응 평가 기준

정책 버전은 `reaction-v1-draft`다. 사용자가 이후 제공할 세부 프롬프트를 적용하기 전의 임시 기준이다. 평가 대상은 발화의 의미·상황 적합성·배려이며, 실제 사용자의 감정이나 목소리 심리를 진단하지 않는다.

| 반응 코드 | 화면 의미 | 임시 기준 | 진행 |
|---|---|---|---|
| happy | 웃음 | 상황에 맞고 필요한 의도가 충분히 전달됨 | 다음 노드 |
| neutral | 무표정, SOSO | 관련 있고 이해되지만 세부 정보·배려·자연스러움은 아쉬움 | 최소 목표 달성 시 다음, 부족하면 재도전 |
| angry | 화남 | 명확한 무례·강요·공격적 표현 | 재도전 |
| sad | 눈물, 서운함 | 명확한 무관심·배려 부족으로 상대를 서운하게 하는 표현 | 재도전 |
| confused | 혼란 | 대화 주제와 무관하거나 현재 맥락에 연결할 수 없음 | 주제를 안내하고 재도전 |

예: 교수님이 제출 가능 시점을 물을 때 구체적인 시간과 계획을 정중하게 제안하면 happy, 가능한 시간만 간단히 말해 최소 의도가 전달되면 neutral일 수 있다. “그냥 기다리세요”처럼 상대를 무시하면 angry, 그 질문에 날씨 이야기만 하면 confused다. 가까운 상대가 기다린 마음을 말했을 때 이를 대놓고 무시하는 답은 sad가 될 수 있다. 같은 문장이라도 관계·앞뒤 맥락에 따라 달라진다.

사유에는 실제 답변의 표현과 상황을 짚는다. 감정이 확정된 사실인 것처럼 설명하지 않는다. 무조건 동의·복종하게 만들지 않으며, 정중한 거절·개인 경계·솔직한 의견 차이는 적절한 대답으로 인정한다. 모국어 답은 neutral과 목표 미달성으로 처리하고 한국어 표현을 알려 준 뒤 다시 말하도록 돕는다.

체력과 보상은 BE가 결정한다. confused·모국어 도움·의도 불명확·AI 오류는 체력을 차감하지 않는다. angry/sad도 명확한 판단(신뢰도 0.75 이상)에서만 차감하며 불확실하면 neutral·재도전으로 낮춘다. 모델은 생명·코인·다음 노드 ID를 결정하지 않는다.

기존 outcome/mark는 호환용이다. FE의 새 평가 화면은 evaluation.reaction과 사유를 사용한다. 중립 상태로 목표를 달성한 답은 진행되며 임시 품질 점수는 웃음 100%, 중립 달성 65%로 반영한다. 이 가중치도 세부 프롬프트와 함께 조정할 임시 정책이다.
