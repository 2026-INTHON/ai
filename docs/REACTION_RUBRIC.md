# 임시 학습 판정 기준

정책 버전 `judgment-v2-draft`. 이후 제공할 세부 프롬프트를 적용하기 전의 임시 기준이다. 학습 판정과 캐릭터의 감정·이미지는 독립적이다.

| 판정 | 의미 | 진행 |
|---|---|---|
| O | 매우 적절한 답변. 의도와 학습 목표를 자연스럽게 충족 | 다음 대사 |
| △ | 맥락에 맞지만 한국어 표현·뉘앙스·구체성이 아쉬움 | 최소 목표 달성 시 다음, 부족하면 재도전 |
| X | 같은 화제 안에서 부적절한 의도, 명백한 무례·강요 | 정정·재도전 |
| ? | 화제와 무관하거나 이해할 수 없는 응답 | 차감 없이 재도전 |

교수님이 제출 가능 시점을 물을 때 정중하게 구체적 시간을 제안하면 O, 시간만 간단히 전해 최소 목표를 달성하면 △일 수 있다. “그냥 기다리세요”는 X, 날씨 이야기만 하면 ?다. 관계와 앞뒤 맥락을 함께 판단한다.

사유에는 실제 답변의 표현과 상황을 짚는다. 정중한 거절·개인 경계·솔직한 의견 차이는 적절한 답으로 인정한다. 적절한 거절은 O이면서 캐릭터 감정은 sad일 수 있다. 감정은 가상 캐릭터의 연기이며 실제 사용자의 심리를 진단하지 않는다.

모국어로 맥락에 맞게 답하면 △·목표 미달성으로 처리하고 한국어 표현을 제안해 재도전을 돕는다. 모국어라도 주제 이탈이면 ?일 수 있다. X 판정 신뢰도가 0.75 미만이면 ?·재도전으로 판단을 유보한다. 불완전·모호한 응답이나 잘못 인식된 것으로 의심되는 발화도 의도를 판단할 수 없다면 ?로 확인한다. 의사소통이 가능한 약간의 직접성이나 어색함은 X가 아니라 △다. O는 사소한 오류를 허용한다.

FE는 `turn.evaluation.mark`와 사유를 학습 판정에, `turn.emotion`·`turn.render`를 캐릭터 표정에 사용한다. AI의 `evaluationMark`가 우선이며 예전 `reaction`은 내부 호환용이다. 과거 기록은 표시 코드만 변환하고 점수·사유는 다시 판정하지 않는다.

체력·보상·진행은 BE가 결정한다. ?·모국어 도움·의도 불명확·AI 오류는 체력을 차감하지 않는다. 임시 품질 가중치는 O 100%, 목표를 달성한 △ 65%다. 점수 가중치와 최소 목표 기준은 추후 조정한다.

사용자가 제공한 「AI 대화 및 학습 과정」을 기준으로 공통 규칙은 `malo_ai/learning_policy.py`에, 실시간 프롬프트는 `providers.evaluate`에, 완료 보고서는 `reports.generate`에 둔다. 성격에 따른 말투·행동과 현재 답변의 관찰 가능한 단서를 함께 사용한다. 힌트 0단계는 없음, 1단계는 주목 표현·행동·상황 단서, 2단계는 설정된 캐릭터 속마음 공개이며 정답을 먼저 강요하지 않는다.

보고서는 문화적 의미·존댓말·비속어·말투·자연스러운 대체 표현을 실제 대화 근거와 연결한다. 첫 답과 재도전의 기존 피드백을 비교하되 수치 개선율을 임의로 만들지 않는다. 다른 관계·성격의 관점 예시는 바뀐 상황과 단서를 명시한다. 잘한 답은 칭찬하며 필요 없는 교정을 만들지 않는다. 보고서는 기록된 판정과 점수를 변경하지 않는다.

## 사용자 제공 12개 기준 사례

`malo_ai/learning_examples.py`의 O·△·X·? 각 3개 예시를 실시간 판정과 피드백의 기준 사례로 전달한다. 같은 문장을 외워 채점하지 않고 실제 관계·요청·앞뒤 맥락을 본다. 특히 “네 교수님. 내일 2시에 갈게요.”는 △, 면담 지시에 대한 “교수님, 내일 수업은 휴강인가요?”는 X, 결론이 끊겨 의도를 파악하기 어려운 응답은 ?로 보정한다. 의미가 명확한 화제 이탈과 의도 자체가 불명확한 응답을 구분한다. 정중한 일정 변경 요청이나 필요한 확인 질문까지 X로 묶지 않는다.
